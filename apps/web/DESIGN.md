# 笺川 v2 · 界面设计规范（UI Spec）

> 适用范围：`apps/web`（v2 前端）。
> 权威实现：`apps/web/src/style.css` 顶部 `:root` 令牌区 + `apps/web/src/components/Icon.tsx`。
> 规则：**组件只许用令牌，不许写裸数值**。新增颜色/字号/间距先加令牌，再在组件里引用。

---

## 1. 设计原则

1. **一套刻度**：字号 8 档、间距 8 档、控件 3 档、圆角 4 档、图标 4 档。没有 12.5px / 13.5px 这种中间值。
2. **对齐优先于好看**：同一行里的按钮、输入框、分段、chip 必须落在同一控件高度上（`--ctl-sm|md|lg`）。高度写死，不靠 padding 撑——padding 撑出来的高度会随字号浮动。
3. **图标是图标，文字是文字**：界面上的图形一律用线性 SVG（24 网格 / 1.7 线宽 / `currentColor`），不再用 ⚙ ✎ ⟳ ✕ 这类字形字符（不同系统字体下笔画、基线、宽窄全不一样）。
4. **层级靠字号 + 字重 + 颜色三者共同表达**，任意一项单独变化不构成层级。
5. **触屏没有 hover**：只在 hover 出现的控件在手机上等于不存在；能力查询（`@media (hover:none)` / `pointer:coarse`）优先于按宽度猜设备。

## 2. 令牌（Tokens）

定义位置：`apps/web/src/style.css` → `:root`。

### 2.1 字号阶梯（rem）

| 令牌 | 值 | 等效 | 用途 |
| --- | --- | --- | --- |
| `--fs-3xs` | 0.625rem | 10px | 角标字母、键盘键帽 |
| `--fs-2xs` | 0.6875rem | 11px | 元信息：来源、时间、标签、计数 |
| `--fs-xs` | 0.75rem | 12px | 辅助说明、chip、小按钮、列表工具条 |
| `--fs-sm` | 0.8125rem | 13px | **界面正文**：频道名、描述、输入框、常规按钮 |
| `--fs-md` | 0.875rem | 14px | **强调正文**：卡片标题、面板正文 |
| `--fs-lg` | 1rem | 16px | 浮层标题（设置/管理/确认框） |
| `--fs-xl` | 1.1875rem | 19px | 阅读层文章标题 |
| `--fs-2xl` | 1.5rem | 24px | 登录页品牌标题 |

行高：`--lh-tight: 1.3`（大标题）· `--lh-snug: 1.45`（卡片标题/描述）· `--lh-body: 1.55`（通用）。
字重：`--fw-regular: 400` · `--fw-medium: 500` · `--fw-semibold: 600` · `--fw-bold: 700`。
字距：`--ls-caps: 0.06em`（全大写小标签）· `--ls-title: -0.01em`（大标题收紧）。

**为什么是 rem**：账号字号偏好（设置 → 外观 → 字号 s/m/l）改的是根字号（16 / 15 / 17.5px），
整套界面按比例缩放；只有全部走 rem 才做得到（旧实现只改 body 的 px，等于只影响没写字号的那几行）。

### 2.2 间距

`--gap-1: 4px` · `--gap-2: 6px` · `--gap-3: 8px` · `--gap-4: 12px` · `--gap-5: 16px` · `--gap-6: 20px` · `--gap-7: 24px` · `--gap-8: 32px`

用法约定：图标与文字 4；同组控件之间 6；控件与标签 8；卡片内边距 / 区块内 12；区块之间 16–20；浮层内边距 24。

### 2.3 控件高度

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--ctl-sm` | 26px | 工具栏里的 chip / seg / 小按钮 / 搜索框 / 行内图标按钮 |
| `--ctl-md` | 32px | 常规按钮、输入框、顶栏图标按钮、侧栏导航行 |
| `--ctl-lg` | 36px | 提示条（toast） |

### 2.4 圆角

`--radius-xs: 6px`（图标按钮、头像、键帽）· `--radius-sm: 8px`（按钮/输入框/行/卡片）·
`--radius: 12px`（列表容器/菜单）· `--radius-lg: 16px`（所有浮层）· `--radius-full: 999px`（chip/胶囊）

### 2.5 图标

`--ico-xs: 12px` · `--ico-sm: 14px` · `--ico-md: 16px` · `--ico-lg: 18px`

- 网格 24×24，描边 1.7，`stroke-linecap/linejoin: round`，`fill: none`；实心态（收藏星、状态点）单独在 path 上给 `fill: currentColor`。
- 颜色一律 `currentColor`：图标不定义自己的颜色，跟随按钮/行的文字色，激活态自动变强调色。
- 新增图标只改 `Icon.tsx` 的 `PATHS`，组件里不写 `<svg>`。

### 2.6 动效

`--dur-fast: 120ms`（hover/按压）· `--dur: 180ms`（展开/切换）· `--ease: cubic-bezier(.2,.7,.3,1)`
浮层登场：`sheet-in` 200ms；提示条：`toast-in` 180ms；刷新图标：`ico-spin` 900ms 线性循环。
卡片入场：`card-in`（上移 6px + 淡入）按 `--stagger: 20ms` 错峰，前 10 张逐张加一档，第 11 张起封顶（长列表不叠成慢动作）。
视图切换（网格 ↔ 列表）：`document.startViewTransition` + `flushSync`；不支持的浏览器直接切。
加载态：骨架 `sk`（1.4s 横向微光）、「还有更多」`load-dots`（三点错峰弹跳）。
状态层：`--state-hover / --state-focus / --state-press` 由 `--text` 调出 8% / 10% / 12% ——
不用 `--glass-2`（浅色主题下白底白，看不见）。
`prefers-reduced-motion: reduce` 下全部压到 0.01ms、取消错峰、关闭玻璃模糊，并跳过视图过渡。

### 2.7 颜色（语义）

| 令牌 | 暗色 | 浅色 | 用途 |
| --- | --- | --- | --- |
| `--bg` | `#1b1a17` | `#f6f6f7` | 页面底 |
| `--surface` | `#25231e` | `#ffffff` | 实底表面（卡片/菜单/手机整屏浮层） |
| `--surface-2` | `#2d2a24` | `#f1f2f4` | 次级表面（输入框/提示条） |
| `--text` | `#eae5db` | `#171a1f` | 主文字 |
| `--muted` | `#a69d8e` | `#6b7280` | 次要文字/图标默认色 |
| `--accent` | `#1f6feb` | 同 | 强调色（GitHub 蓝） |
| `--danger` | `#f2836f` | `#c0392b` | 危险/错误 |

派生令牌：`--accent-soft`（强调色 18% 底）、`--glass / --glass-2 / --glass-border`（玻璃面）、
`--sheet / --sheet-border`（浮层）、`--line / --line-strong`（分隔线）。**不要写死 rgba**。

## 3. 组件规范

### 3.1 按钮

| 形态 | 规格 | 用法 |
| --- | --- | --- |
| `.btn` | 高 32 / 内距 0 12 / 圆角 8 / 字号 13 / 图标 14 | 常规动作 |
| `.btn.primary` | 强调色底 + 白字 / 600 | 每个视图最多一个（提交、确定） |
| `.btn.ghost` | 透明底 | 次要动作、图标按钮 |
| `.btn.sm` | 高 26 / 内距 0 8 / 字号 12 | 工具条、行内动作 |
| `.btn.icon` | 32×32 正方形 | 顶栏、浮层关闭 |
| `.icon-btn` | 26×26 / 圆角 6 / 图标 14 | 列表行内的刷新/暂停/删除 |

按钮内图标与文字间距 `--gap-2`（小按钮 `--gap-1`）；**居中而非左对齐**，一行并排时文字基线才齐。

### 3.2 输入

`.input` 高 32、内距 0 12、圆角 8、字号 13；`.input.sm` 高 26、字号 12。
聚焦：边框变强调色 + `0 0 0 3px var(--accent-soft)` 光晕（不用 outline 偏移，避免撑破容器）。
带搜索图标的输入框：`padding-left: 27px`，图标绝对定位 `left: 8px`，`pointer-events: none`。

### 3.3 chip / seg / tag

- `.chip`：高 26、圆角全、字号 12；用于页签与筛选；激活 `--accent` 文字 + 边框 + `--accent-soft` 底。
- `.seg-btn`：高 26、圆角全、字号 12；同组互斥档位，激活为实底强调色。
- `.mini-tag`：字号 11、内距 0 6；**只在阅读层正文的元信息里出现**，点一下 = 按该标签筛列表并退出阅读层。
  卡面标签与顶部标签云按 v1 1.6.0 / 1.7.0 的决策已移除（`TagBar`、`.tag-btn` 不要加回来）；
  标签筛选的唯一出口是列表标题旁的 `.scope-x`。

### 3.4 侧栏导航

- 行高 32（`.gview` / `.feed`），内距左 8、右 6；图标列固定 18；计数右对齐、等宽数字、字号 11。
- 激活态统一「`--accent-soft` 底 + 2px 左侧强调条 + 边框」；悬停只加 `--glass-2` 底，不加边框。
- 分组标题：高 26、字号 11 / 600 / 大写字母距，左边界与频道行对齐。
- 频道行**只有一行**：失败 / 隐藏这类状态用 `.feed-flag` 徽章（11px、胶囊、`--line` 描边，危险态转 `--danger`）挂在名字右侧，**不要再加第二行副标题**（行高会从 32 涨到 48，和全局视图行错位）。

### 3.5 卡片与列表

- 卡片内距 12，图文间距 12，封面 116×76 圆角 8；标题 14/600/1.45，描述 13/次要色/2 行截断，元信息 11。
- 网格模式标题最多 2 行；手机（≤560px）为横向紧凑行（封面 110×84）。
- 未读标记：左上角圆点（网格压封面、列表落左侧槽），已读不变暗。
- 加载态：6 张骨架卡（`.card-thumb.sk` + `.sk-line` 三条）。出现的判据是**当前没有条目**，
  不是 `isPending` —— 换范围时 keepPreviousData 会保留旧数据，`isPending` 已经是 false。

### 3.6 浮层（reader / prefs / admin / digest / cmdk / confirm）

统一：圆角 16、内距 24、玻璃底 `--sheet` + `backdrop-filter`、边框 `--sheet-border`、`sheet-in` 登场。
标题：16 / 600 / 行高 1.3。
阅读层工具条（`.reader-tools`：字号 A-/A+ + 关闭）在流内吸顶，实底 `--surface`、不模糊。
关闭按钮 `.reader-close` 32×32、图标 16，跟着工具条走（不再绝对定位到标题右上）。
吸顶 `top` 按**可视视口**算，不是滚动容器的 padding：桌面档浮层有 40px 外距就写 `top: 40px`（`--reader-sticky`），手机整屏档写 0。
浮层内小标题（`.admin-h3`）：11 / 600 / 大写 / 字距 0.06em / 次要色。
窄屏（≤820px）：阅读层改为整屏**实底** `--surface`、遮罩压成 `--bg`、关闭模糊（全屏浮层必须不透）；
设置/管理面板与确认框仍是浮层，保留玻璃底。命令面板 ≤560px 才整屏。

### 3.7 提示条

胶囊、最小高 36、内距 0 16、字号 13、前置图标 14（成功 ✓ / 失败 ⚠），圆角全、`--surface-2` 底。
失败态文字与边框转 `--danger`。点击关闭。

### 3.8 确认框

宽 420、内距 16、圆角 16；标题行 = 32px 图标徽章（危险动作用 `--danger` 底）+ 标题；
正文左侧缩进与图标列对齐；底部动作右对齐（取消 → 确定），危险动作按钮用 `.btn.danger`。

### 3.9 全屏灯箱与 portal

灯箱（`.lightbox`）必须 `createPortal` 到 `document.body`。

`backdrop-filter` / `transform` / `filter` 的祖先会给 `position: fixed` 的后代**新建包含块**：灯箱留在阅读层树里时只会铺满阅读层那一列，`top: 50%` 也按整张长 sheet 计算，左右翻页箭头会被推到视口之外（真实踩过：视口 960，箭头 y=1053）。
往玻璃浮层里塞任何全屏元素（灯箱、全屏预览、拖拽遮罩）都照此办。

### 3.10 吸顶与玻璃治理

- 吸顶只允许两处：列表工具块 `.list-bar`（标题/排序/视图/搜索）与阅读层 `.reader-tools`。
  两者都是**实底**（`--surface` / `--bg`），绝不给吸顶条加 `backdrop-filter`：
  滚动时每帧都要重采样模糊，必掉帧（v1 用性能实测换来的规矩）。
- 吸顶的包含块是最近一个块级祖先的**内容盒**，不是 padding 盒：父级有上内距时，sticky 子元素进不去那一段（所以阅读层要把上内距同时写进 `top`）。
- `display: grid` + `place-items: stretch` 会把子项拉到轨道高；子项里的 sticky 因此只剩一屏的活动范围，看起来「滚两下工具条就没了」。
  窄屏整屏阅读层必须显式 `align-self: start`（真实踩过：sheet 被钉在 844，内容 2959）。
- `backdrop-filter` 只留给静止表面（顶栏、桌面浮层）；自滚动容器、全屏浮层、吸顶条一律实底。

## 4. 布局节奏

- 顶栏：高 32 控件 + 上下 8 → 约 48–52px；左右内距 20，与列表内容左边界对齐；分组间距 16 / 8 / 12。
- 侧栏：左右内距 8，块间距 12，行距 1（行内自身高度承担节奏）。
- 列表：内距 上 12 / 左右 20 / 下 32；工具块 `.list-bar` 里两行（标题行 + 动作/筛选行）共用同一左右内距、上 0 / 下 8，整块吸顶。标签那一行随标签云一起移除（v1 1.6.0）。
- 阅读层：内距 24；标题下 6、元信息下 16、正文下 20 接动作条。

## 5. 交互状态

| 状态 | 表现 |
| --- | --- |
| hover | 背景 `--glass-2`；边框最多到 `--line-strong`；不加位移 |
| active | 背景再加一档（`color-mix(text 14%)`），仍不加位移 |
| focus-visible | 2px 强调色 outline + 2px offset；输入框用 3px 柔光 |
| disabled | `opacity: .5` + `cursor: default`；分段按钮 `.45` |
| 触屏 | `@media (hover:none)` 操作按钮常显；`pointer:coarse` 下按 v1 实测尺寸抬命中区：关闭 40×40、行内图标 32×32、收藏 34×34、菜单项 ≥44 高。改的是**真实盒尺寸**（宽高/内距），不用伪元素外扩 —— 外扩会压住相邻可点区域。 |

## 6. 检查清单（改界面时逐条过）

- [ ] 新增数值是否已有令牌？没有就先加令牌。
- [ ] 同一行控件是否同高（26 / 32 / 36）？
- [ ] 图标是否来自 `Icon.tsx`？是否 `currentColor`、尺寸走 `--ico-*`？
- [ ] 浮层是否 16 圆角 / 24 内距 / 关闭按钮 32×32 同位置？
- [ ] 字号是否只用了 8 档之一？层级是否同时靠字号+字重+颜色表达？
- [ ] 触屏下能否点到？（`ui-shots` 会检查 `hover:none` / `pointer:coarse` 规则覆盖）
- [ ] 新增的吸顶条是否实底、有没有顺手加 `backdrop-filter`？sticky 的 `top` 是否按可视视口而不是父级 padding 算？
- [ ] 阅读层里点正文标签是否仍然「筛列表 + 退出文章」一步完成？（走 store 的 `tagFromEntry`，别拆成两次 set）
- [ ] `node scripts/verify-dist.mjs` + `scripts/ui-check.mjs` + `scripts/ui-shots.mjs` 全绿？
