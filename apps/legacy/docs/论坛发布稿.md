# 笺川 FeedLore：自己架一个干净的 RSS 阅读器，追更和囤资源都能放一处

**轻量化、没有广告和追踪，读过的东西都存在你自己的服务器上。**

- 先点着玩：**https://feedlore.669600.xyz** （账户 `demo` / 密码 `demo`，所有功能都能试）
- 源码在这：**https://github.com/chensnails/FeedLore** （MIT，随便用）
- 装法：一条命令起一个容器，装完升级也不用管

![文章阅读页](https://raw.githubusercontent.com/chensnails/FeedLore/main/docs/screenshots/02-reader.png)

## 为什么又做一个

我自己的订阅里有一大半是「资源向」的：剧集、软件、网盘分享、带提取码的长帖。这类内容在常规阅读器里被压成一行标题，想看图得跳回源站，跳回去还得翻半天评论区。所以它做成了两个页面：

- **文章页**就是你熟悉的那种阅读器：左边频道（可以分组），右边列表，点标题直接在原地展开全文，图片按原文顺序排好，不用跳走。
- **卡片墙**是给你囤的东西用的：网格或列表卡片，有封面、标签、大小，点卡片直接弹出来看全文，收藏留在这一层。

两个页面互相认识。在卡片里点「在文章页查看」，它会切过去、滚到那一条、让它闪一下描边——不用自己在几百条里翻。

![卡片墙](https://raw.githubusercontent.com/chensnails/FeedLore/main/docs/screenshots/03-cards.png)

## 你大概会用到这些

| 想干什么 | 怎么弄 |
| --- | --- |
| 日常追更 | 点标题就地读全文；已读 / 未读 / 收藏分开记；顶部搜索能搜标题、摘要和正文；可以开着让它自己刷新 |
| 加订阅 | 粘贴 RSS 地址，或者一次性导入 OPML（带分组，重复的自动去掉）。频道名字能改、订阅地址能改、分组能重命名也能拖着排序 |
| 少看点噪音 | 每个账号自己一套过滤规则：写关键词或者正则，选「只要这些」或「屏蔽这些」，可以只针对标题或正文 |
| 图片别裂 | 源站防盗链是常事，这里的图统一从你自己的服务器转一道，不会出现满屏裂图 |
| 换外观 | 4 套主题（跟随系统 / 浅色 / 暗色 / GitHub 暗黑）配 6 种主色，字号、字体、行高、正文宽度都能调，点一下就生效 |
| 家里几个人一起用 | 管理员建账号，没有公开注册。每个人的订阅、已读、收藏、过滤规则都是分开的，互不干扰 |
| 手机上用 | 窄屏下弹窗是整屏推进来的，往下拉就能关掉；用 HTTPS 访问时「添加到主屏幕」，跟 App 一样打开 |
| 定时整理 | 想要的话，在「设置 → 模型」填你自己的大模型 Key，就能把过去 24 小时的新内容整理成一份中文简报。不填也不影响任何别的功能 |

![卡片详情弹窗](https://raw.githubusercontent.com/chensnails/FeedLore/main/docs/screenshots/04-card-detail.png)

有几个省心的小地方：抓取一直失败的频道会自己停掉并告诉你原因，不会天天弹错；旧内容可以按条数或天数自动清理；某个源挂了图片也不会连累你的页面。

## 装一份要多久

前提是有 Docker。把下面这段直接粘进终端，大概一分钟：

```bash
git clone https://github.com/chensnails/FeedLore.git
cd FeedLore
cp .env.example .env

# ⚠️ 这两行是给数据库和更新通道生成随机密码，务必执行，别用默认的弱口令
sed -i "s#^PG_PASSWORD=.*#PG_PASSWORD=$(tr -dc 'A-Za-z0-9' < /dev/urandom | head -c 32)#" .env
sed -i "s|^WATCHTOWER_HTTP_API_TOKEN=.*|WATCHTOWER_HTTP_API_TOKEN=$(openssl rand -hex 32)|" .env

docker compose -f docker-compose.release.yml up -d
```

然后浏览器打开 `http://<你的服务器IP>:3210`，第一次的账号密码是 `admin / admin`，登录后马上去「设置 → 账号」改掉。接着到「设置 → 数据源」粘贴几个 RSS 地址，或者导入你的 OPML，就能开始读了。

以后升级也不用你动手：作者发新版，你这边会自动跟着更新；不想等的话，「设置 → 关于 → 检查更新」里有个「一键更新」。

## 说清楚它的边界

- **不开放注册**：定位是个人和小圈子用，账号由管理员建。
- **没有应用商店里的 App**：手机端走网页装到主屏幕，离线时能打开界面，但读不到新内容。
- **AI 简报要自备 Key**：不填 Key 就没有任何第三方调用，其它功能照常。
- **演示站是共享的**：`demo` 账户大家共用，数据会变动也会重置，别把重要订阅放进去。
- **备份要自己安排**：所有数据都在那一个数据库卷里，定期备份一下（这句不是客套）。
