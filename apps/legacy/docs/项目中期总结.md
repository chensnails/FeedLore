# 笺川 · FeedLore 项目中期总结

> 截至 2026-10-23 · 本文档只留本地，不入库

## 一、项目概况

- **定位**：自托管 RSS 阅读器 + 资源卡片墙，多用户、无广告、无遥测，数据全部落自己的 PostgreSQL。
- **周期**：2026-10-18 v1.0.0 首发 → 2026-10-23 当前 v1.3.7（未打 tag），共 6 天、54 次提交。
- **技术栈**：后端 Node 22 原生 `http`（无框架）+ PostgreSQL 直连（无 ORM）；前端 Vite + React 19，`core` 单例桥接共享状态；单容器部署，amd64/arm64 双架构镜像。

## 二、已交付的核心能力

### 阅读与内容

- 左频道（分组）右文章，就地展开全文；已读/未读/收藏、服务端全文搜索、自动刷新。
- 图片按原文顺序内联，统一走 `/api/img` 服务端代理（防盗链不裂图，两级缓存 + WebP 压缩）。
- 条目过滤：关键词/正则「只收/屏蔽」，入库前逐账号生效。
- 可选 AI 日报：用户自带 Key，按账号整理 24h 新条目成中文简报。

### 订阅管理

- OPML 导入/导出（含分组、去重）、频道/分组重命名、拖拽排序、单频道抓取频率。
- v1.3.0 新增「修改订阅地址」，换址自动清 ETag/失败计数并当场试抓。
- 死链频道连续失败自动停用并提示。

### 卡片墙与双视图联动

- 网格/列表卡片，频道/标签筛选与搜索，点卡片弹详情看全文。
- v1.3.7 卡片详情「在文章页查看」→ 跳转 + 滚动定位 + 描边高亮（最多翻 8 页找目标）。

### 移动端体验（v1.3.x 重点）

- 弹层一律整屏推入、统一下拉关闭手势（v1.3.4–1.3.6）。
- PWA 可安装，Service Worker 缓存外壳，`/api` 网络优先。

### 多用户与外观

- 账号由管理员创建，订阅/已读/收藏按账号隔离；模型配置按账户绑定。
- 4 主题 × 6 主色，字号/字体/行高/阅读宽度可调。

## 三、工程与发布基建

- **CI/CD**：推送 git tag → GitHub Actions 双原生 runner（amd64 + arm64）构建镜像推 ghcr.io 并建 Release；v1.2.0 用原生 runner 替换 QEMU 模拟解决 arm64 构建超慢。
- **自动更新**：镜像模式配 Watchtower，「设置 → 关于」一键更新；未发布的 v1.3.7 把 watchtower 容器改名 `feedlore-watchtower` 避免宿主机撞名。
- **测试**：UI 回归 261/261 + 服务端 77/77，随功能同步补测试。
- **设计系统**：v1.1.12/1.1.14 两轮 UI 审查，统一圆角/字号/间距/阴影/动效设计令牌，补齐焦点态与禁用态。
