## 本轮改动落点（#6 / #7 / #9 / #10）

- **#6 密度偏好**：`lib/prefs.js` 与 `src/core/state.js` 双端 `appearance` 白名单新增 `density`（cozy/compact）；
  `src/settings/AppearancePane.jsx` 加分段控件；`public/style.css` 加 `:root[data-density="compact"] .grid { minmax 收紧 + gap 减小 }`。
- **#7 频道内搜索**：`src/views/ChannelList.jsx` 增加本地搜索态，按频道名过滤（保留分组、命中即展开），顶部加搜索框 + 清空 + 无匹配空态；
  `public/style.css` 加 `.rd-ch-search` 样式。两页抽屉共用，不改父组件传参。
- **#9 降阴影**：`public/style.css` 三主题各降 `--neu-shadow*` 双向阴影约 40%，浅色主题降 `--shadow` 卡片静止阴影；
  保留 hover 交互阴影、浮层 `--shadow-lg`、toast 阴影不变。
- **#10 站内确认**：`src/core/reader.js` 的 `readerReadAll` 复用统一 `confirm`（已是站内 dialog，非原生），
  按 `readerFilterParams` 的 feeds 过滤聚合 `feed.unreadCount` 得出受影响未读篇数，写入确认框 `desc`（`影响 N 篇`；favorite 范围退化不显示数字）。
