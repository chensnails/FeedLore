## 维护约定

1. **产品规则变了** → 先改 `产品文档.md`，再改 `帮助文档.md` 的对应用户操作。
2. **每个正式版发布后** → `CHANGELOG.md` 记版本内容；`开发日志.md` 补一行里程碑（有决策或新坑再各补一条）。
3. **文档与代码冲突时以代码为准**，但要把文档改回来 —— 文档过期比没有更误导。
4. 本目录的 HTML 报告是**历史快照**，不随版本更新；结论已过期的在文件名或正文里注明日期。
