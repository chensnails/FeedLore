界面与交互全面优化方案

以 Google Material Design 3（角色化色彩、状态层、动效即语义、可达性内建）、 Apple Human Interface Guidelines（Clarity 清晰 / Deference 克制 / Depth 纵深，44pt 触控、语义色、reduce-motion）、 以及 主流 RSS / 阅读器范式（Reeder、NetNewsWire、Readwise Reader、Inoreader、Feedly 的键盘优先、命令面板、阅后自动标记、三栏、状态点、撤销） 为三重视角，对当前 v1.6.0-test6 界面做全面诊断，并给出按维度结构化的改进要点、设计建议与预期效果。

五个最值得优先补的缺口

  • 动效几乎没有「入场/转场」：当前仅有 spin/ddPush/sk 三个 keyframes，模态、视图切换、卡片列表均无动画；prefers-reduced-motion 仅覆盖 ddPush 一处。
  • 主导航被埋进溢出菜单：三视图（文章/卡片/日报）切换藏在 ⋮ 里，违反「3–5 个一级目的地用常驻导航」（Apple）/「持久侧栏或标签栏」（阅读器范式）。
  • 状态层（hover/focus/press）是零散硬编码，而非 MD3 式的「on-color 低透明度叠加」系统——跨主题一致性靠人工维护，易漂移。
  • 卡片页丢失未读信号：仅剩收藏★，缺少 RSS 用户习惯的未读强调与常驻「全部/未读/收藏」切换（Inoreader 范式）。
  • 设置内「关注/屏蔽」切换自造控件：.watch-act-btn 形状/阴影与全站共用的 .seg 不一致（前期审计已发现）。

1方法论：三个对标透镜

本方案每条建议都标注其所依据的透镜，确保建议有出处、可取舍，而非主观审美。

MD3 Material Design 3

角色化色彩（primary/secondary/tertiary/error/surface 成对保证对比）；4dp/8dp 栅格；排版角色（display/headline/title/body/label）；形状刻度； 状态层（hover 8% / focus 10% / press 12% / drag 16% 的 on-color 叠加）；动效即语义；touch target ≥48dp；可达性内建。

Apple HIG

八大原则（Purpose/Agency/Responsibility/Familiarity/Flexibility/Simplicity/Craft/Delight）；三基石 Clarity / Deference / Depth； 触控目标 ≥44×44pt；语义色自适应明暗；纵深靠半透明与真实动效；弹簧缓动；尊重 reduce-motion。

RSS 阅读器范式

键盘优先（j/k、⌘K 命令面板）；阅后自动标记；三栏/两栏布局；状态色点；撤销（Z）；稳定常驻顶栏（少动、少移位）； 专注阅读（聚焦模式、正文字宽 ~66 字符、行高 1.5–1.8）；「全部/未读」常驻切换 + 实时未读计数。

落地约束：当前 CSS 采用「按功能就近、同特异度靠源顺序取胜」的多段式结构（约 6 段 @media(max-width:720px) 不可合并，合并实测 181 处偏差）。因此所有建议优先以「新增收敛层 / 复用既有令牌 / 复用既有组件」方式落地，避免触碰脆弱的层叠顺序。

2视觉设计

2.1 布局与信息架构 Apple·一致性 RSS·导航

现状

三视图各自拥有结构不同的吸顶工具条：卡片 [≡][频道][搜索][⋮]、文章 [≡][标题][动作][搜索][⋮]、日报 [AI][⋮]。左侧 ChannelList 侧栏 + 卡片网格/列表 + 文章页两栏。视图切换入口在溢出菜单 ⋮ 内。

问题

① 三个顶栏信息结构不一致，违反 Apple「一致的外观与行为」与 MD3「可预测的界面」； ② 一级导航（3 个视图）被发现成本高——Apple 推荐 3–5 个一级目的地用常驻标签栏/侧栏，阅读器普遍用持久导航轨； ③ 间距未严格落在 8px 栅格（存在零散 px）； ④ 缺少阅读「聚焦模式」。

设计建议

  • 统一 App Bar 模式：三视图共用同一套顶栏骨架（≡ 抽屉 · 上下文标题/频道 · 搜索 · 主要动作 · ⋮），仅中间区随视图变化。用 CSS 变量在工具栏子树内覆盖，不动 :root 已钉死的值（遵循现有纪律）。
  • 把视图切换提升为常驻导航：桌面用左侧细导航轨（图标 + 文字），移动端用底部标签栏；溢出菜单只放次级功能（排序、网格/列表、设置、主题）。见图 C。
  • 8px 栅格审计：对工具条、卡片网格 gap、列表行高做一次间距收敛，统一引用 --sp-*。
  • 阅读聚焦模式：文章页一键隐藏侧栏与顶栏（Deference 克制），并提供「加宽正文」开关（在现有 --reader-width 基础上加一档 ~60rem）。

预期效果

导航成本下降、三视图「看起来是同一个产品」；移动端拇指可达；阅读时干扰减少，专注度提升。

2.2 色彩与表面语言 MD3·表面 Apple·Depth

现状优势

角色化主色 --accent* + 语义令牌；对比度意识强（如 --star 为达标 4.5:1 而调整）；拟态（neu）用于长列表、玻璃（glass）仅用于已锁滚动的弹层——分工正确。

问题

① 拟态「浮起」与玻璃「半透」两套表面语言并存，部分用户感知「界面发飘、层次弱」（v1.4.0 降阴影后浮起深度从 13 掉到 11 已知）； ② 状态层是零散硬编码：hover 用实色 --hover，focus 用 --focus-ring，press 用 translateY，未形成「on-color 低透明度叠加」系统； ③ 按钮层级未形式化（filled / tonal / outlined / text 区分不清）。

设计建议

  • 引入 MD3 状态层令牌：--state-hover:.08、--state-focus:.10、--state-press:.12、--state-drag:.16，以「on-surface / on-accent 的对应透明度」实现。统一用叠加层而非改背景色，使明暗三主题与 6 主色自动适配。
  • 把表面策略写成文档约束：in-flow 浮起元素用 neu；真正的覆盖层（modal/cmdk/lightbox）用 glass；明确禁止在 sticky/fixed 长列表上用 backdrop-filter（现有铁律，纳入设计文档）。
  • 形式化按钮层级：.btn-primary（filled，最高强调）/ .btn-tonal（accent-soft 填充，次级）/ .btn-outline（描边）/ .btn-text（纯文字）。当前 .btn-ghost 可映射为 tonal/outline。

预期效果

跨主题一致的悬停/按下反馈；主/次操作一眼可辨；表面语言「有章法」，不再依赖个别校准。

2.3 排版与可读性 MD3·排版 Apple·Clarity

现状优势

字号阶梯 --fs-2xs(11)…--fs-2xl(21) 已收敛；正文 --reader-fs:1rem、行高 1.8（对中文友好）、正文字宽 47.5rem 合理。

问题

① 字号是「数值刻度」而非「角色刻度」，缺 display/headline/title/body/label 语义映射； ② 次级文字 --text-muted:#57616f/--text-faint:#66717f 在亮色下对比度偏临界； ③ 标题字重/字距不统一，卡片标题存在截断； ④ 全局字号缩放仅阅读页支持（--reader-fs），未像 Dynamic Type 那样覆盖全应用。

设计建议

  • 为字号令牌补「角色别名」：--fs-title = --fs-lg、--fs-body = --fs-base、--fs-label = --fs-sm 等，组件引用角色名，便于统一调权。
  • 提升次级文本对比：将 --text-muted 压到 ~#4a5563、--text-faint 到 ~#586474（亮色下 ≥4.5:1）。
  • 标题字重刻度：页面主标题 700、区块标题 600、卡片标题 600、正文 400，配 letter-spacing 微调。
  • 全应用字号缩放：把「阅读字号」机制推广为根 html 的 font-size 偏好（rem 已就绪），满足 Apple「Dynamic Type / 200% 缩放」可达性。

预期效果

层级更清晰、长文更省力；可达性达标；中文阅读节奏统一。

2.4 视觉层次与状态表达 RSS·状态 MD3·层级

问题

① 卡片页移除了未读/已读态（仅收藏★），削弱「分拣」信号；RSS 用户普遍预期未读强调 + 常驻「全部/未读/收藏」切换与实时计数（Inoreader 范式）； ② 收藏/屏蔽/关注等状态缺少统一的「图标 + 颜色」语言； ③ 空态/品牌视觉权重可加强。

设计建议

  • 恢复轻量未读信号：卡片用「左侧 accent 细条 / 标题加粗 / 已读项降透明度」表达，而不必回到重色块；并在工具条加入常驻 全部 / 未读 / 收藏 分段（复用 .seg，对齐 Inoreader 的常驻 pill）。
  • 统一状态语义：favorite=★+金；watch=👁+主色；block=⊘+中性灰；用一致的形状/颜色编码。
  • 品牌化空态：空结果/无订阅/首屏引导用带行动按钮（CTA）的插画式空态，而非纯文字。

预期效果

分拣效率提升、符合阅读器心智模型；状态一眼可辨；空态从「终点」变「起点」。

3动效与过渡

现状

令牌 --dur-fast:.12s / --dur-base:.15s / --dur-med:.18s / --dur-slow:.22s、--ease:cubic-bezier(.2,.8,.3,1)；过渡多用于 hover/transform/box-shadow。 全局 @keyframes 仅 spin（加载）、ddPush（下拉从底部推入，带 reduce-motion 守卫）、sk（骨架微光）。 模态、视图切换、卡片列表均无入场/出场动画；缓动用法不统一（部分用 ease、部分用 var(--ease)）；prefers-reduced-motion 仅 ddPush 一处。

问题（对照 MD3「动效即语义」+ Apple 弹簧缓动）

① 没有动效尺度：微交互/组件/转场混用同一档 ~150ms，缺少 250–350ms 的「有意义的转场」； ② 缺少入场/转场：卡片列表、模态、视图切换硬切，失去空间连贯（Apple Depth）； ③ 动效未承载语义：自动加载的新条目、新内容浮标、标记已读都没有「告知性」动效； ④ reduce-motion 未全局化。

设计建议

  • 定义动效尺度令牌：--dur-1:.15s（微交互）/ --dur-2:.25s（组件）/ --dur-3:.35s（转场）；并补三种缓动：--ease-std:cubic-bezier(.2,.8,.3,1)（去强调）、--ease-emph:cubic-bezier(.3,0,.8,.15)（强调/弹簧感）、--ease-decel:cubic-bezier(0,0,.2,1)（入场减速）。
  • 入场动画：卡片列表 stagger（translateY(8px)+opacity，每项 40ms 递增）；模态 scale(.96→1)+fade；视图切换（卡片↔文章）用轻微 slide/scale 保持空间方向。
  • 告知性动效：自动加载的新条目 fade-up 进入；「有新内容」浮标平滑出现/消失；标记已读用标题颜色轻过渡。
  • 全局 reduce-motion：在 :root 末尾加 @media (prefers-reduced-motion: reduce){ *{animation-duration:.01ms!important;transition-duration:.01ms!important} }，仅保留必要的 opacity 变化。

预期效果

界面「活起来」且自然；转场提供空间连贯（Depth）；自动加载/新内容有明确反馈；前庭敏感用户不被眩晕。

4交互体验

现状优势

命令面板已绑定 ⌘K/Ctrl K（键盘优先雏形）；溢出菜单可访问性完整；自动加载下一页已生效；关注/屏蔽规则 + webhook 已落地；滚动用 capture 监听（App Shell 下可用）。

问题（对照 RSS 范式 + Apple Agency/Familiarity + MD3 触控）

① 主视图切换被发现成本高（见 2.1），命令面板虽好但缺「快捷键帮助」入口（?）； ② 键盘文章导航不完整：j/k 上下篇、o 打开、e 已读/归档、s 收藏、/ 搜索 等未系统性提供； ③ 缺撤销：批量「全部已读」等破坏性/批量操作无 undo（Apple Agency「容错」、Readwise 的 Z 撤销）； ④ 阅后自动标记未默认：Reeder/Inoreader 支持滚动即已读（按账户开关）；当前仅「打开详情=已读」； ⑤ 乐观更新/内联进度有限：收藏等动作可加轻量 spinner→落定反馈； ⑥ 触控目标审计不全**：粗指针 40–44px 已治理，但需全量复核所有可点击元素 ≥44×44pt（Apple/MD3 硬指标）； ⑦ 首次引导/空态缺引导； ⑧ 设置内自造控件 .watch-act-btn 与 .seg 不一致（见前）。

设计建议

  • 常驻主导航 + 保留溢出菜单放次级（呼应 2.1）；命令面板增补「快捷键一览」（? 或 h 打开）。
  • 键盘优先地图：j/k 上下篇、o 打开、e 已读、s 收藏、/ 搜索、u 撤销、? 帮助；在 hover tooltip 与命令面板显示快捷键。
  • 撤销（Toast Action）：批量/破坏性操作后弹 toast 带「撤销」按钮（如「已标记 32 篇为已读 · 撤销」）。
  • 阅后自动标记（账户级开关）：默认关、可开；滚动出视口即标记，符合阅读器习惯。
  • 乐观 UI + 内联反馈：收藏/标记先本地置态再落库，失败回滚并提示。
  • 触控目标全量审计：确保所有交互元素 ≥44×44pt；press 态用状态层（2.2）给出清晰触感。
  • 首屏引导 + 行动化空态：新用户 3 步引导；空态带 CTA。
  • 统一设置控件：把 .watch-act-btn 改为复用 .seg（最少改动：补 box-shadow:var(--neu-inset) 并对齐选中语言）。

预期效果

高手键盘流提速数倍；误操作可挽回（安心探索）；移动端拇指舒适；首次使用不再茫然；设置控件「一个系统」。

A. 建议新增令牌（在 :root 设计系统段内追加，复用既有一致性注释风格）

/* 状态层（MD3：on-color 低透明度叠加，跨主题/主色自动适配） */
--state-hover: rgba(31,92,232,.08);   /* 桌面悬停 */
--state-focus: rgba(31,92,232,.10);  /* 键盘聚焦 */
--state-press: rgba(31,92,232,.12);   /* 按下 */
--state-drag: rgba(31,92,232,.16);    /* 拖拽 */

/* 动效尺度（时长 + 缓动，取代单一 ~150ms） */
--dur-1:.15s;  --dur-2:.25s;  --dur-3:.35s;
--ease-std:   cubic-bezier(.2,.8,.3,1);
--ease-emph:  cubic-bezier(.3,0,.8,.15);
--ease-decel: cubic-bezier(0,0,.2,1);

/* 字号角色别名（数值刻度之上叠加语义名） */
--fs-display:var(--fs-2xl); --fs-title:var(--fs-lg);
--fs-body:var(--fs-base);   --fs-label:var(--fs-sm);
